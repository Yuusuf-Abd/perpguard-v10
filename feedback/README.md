# Feedback track

Create **one Markdown file per genuine, independently reproducible issue** in this folder, based on `TEMPLATE.md`. Use the organizer-required severity (`critical`, `major`, `normal`) and area (`API`, `SDK`, `docs`, `app`, `contracts`). Do not submit fabricated bug reports. Include steps, expected/actual behavior, evidence, SDK version, Somnia Tokyo testnet information and a public wallet address if relevant.

**Security issues:** Do not publish them here; email **security@dreamdex.io** privately. Remove private keys, recovery phrases, session tokens, and personal information from all evidence.
