# PerpGuard v11 — Visual update

## Implemented
- Original dark violet visual theme inspired by the supplied Somnia references (not copied from Somnia).
- Space Grotesk headings, Inter interface font with system fallbacks.
- Subtle grid and ambient gradient background, updated sidebar, hover/focus states.
- Reduced-motion accessibility support.
- Existing v10 frontend, backend, paper portfolio, and tests preserved.

## Not implemented or verified
- No dreamDEX SDK/API integration, wallet signing, or testnet perpetual-order execution.
- No whitelist approval, social publication, or live deployment.
- The external Google Fonts stylesheet requires network access; fallback fonts are provided.
- Full TypeScript build and live browser verification have not been performed in this packaging step.

Do not submit this release as evidence of dreamDEX SDK usage or testnet transactions.
