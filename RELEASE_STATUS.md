# PerpGuard v10 — release status

PerpGuard v10 retains the v9 interactive analytics and paper trading application, and adds CI configuration, a demo recording script, accurate social post drafts, a submission checklist, and an evidence log.

**Not implemented:** actual dreamDEX Somnia testnet perpetual order execution, wallet signing, or real cryptocurrency transfers. Paper trading is simulated. This project is **not Track B compliant**.

**External actions not completed:** GitHub publishing, HTTPS deployment, demo recording, X posting, whitelist approval, and DoraHacks submission. These require real accounts, actions, and evidence.

Build/browser and live external API verification remain unconfirmed until performed in a connected environment.
